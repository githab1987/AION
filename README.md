# AION

**Autonomous Intelligence-Oriented Notation**

AION is a language and runtime for turning intention into reality while never confusing creation with truth.

## Core Principle

> Declare what matters. Allow what is possible. Observe what happened. Prove what is true.

## Semantic Cycle

DECLARE → SEEK → ACT → OBSERVE → PROVE → BECOME

When reality does not satisfy the intention:

REPLAN → SEEK

When execution must stop:

STOP

## Semantic Core

AION is built around these concepts:

- HUMAN
- BEING
- WORLD
- INTENTION
- CAPABILITY
- ACTION
- ARTIFACT
- STATE
- OBSERVATION
- EVIDENCE
- VERIFY
- MEMORY
